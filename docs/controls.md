# Controls

|                         | Keyboard                    | Gamepad                    |
| ----------------------- | --------------------------- | -------------------------- |
| Steer left, right       | `A` `D` or `←` `→`          | Left stick or D-pad        |
| Steer up, down          | `W` `S` or `↑` `↓`          | Left stick or D-pad        |
| Move through a menu     | `W` `S` or `↑` `↓`          | D-pad up and down          |
| Confirm                 | `Space` or `Enter`          | `A` (bottom face button)   |
| Pause, resume           | `Esc`                       | `Start`                    |

You always fly forward; steering turns you. Pushing the left stick up steers up, like `W`. You can hold two directions at once to turn diagonally.

In the pause menu, `Esc` or `Start` resumes the game. On the **Controls** screen, `Esc`, `Start` or the confirm button goes back to the start menu.

Any connected gamepad works, and you can use the keyboard and a gamepad at the same time.
